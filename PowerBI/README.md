## 🚀 How to Use

1. Clone or download this repository.
2. Open `PowerBI/ElectroHub-Sales-Analysis.pbix` using **Power BI Desktop**.
3. If Power BI asks for the source-data location, update the data source path.
4. Refresh the model if required.
5. Navigate through the five report pages.
6. Use the slicers and visual interactions to explore the data.

### Recommended Power BI Version

Use a recent version of **Power BI Desktop** because the report uses the current Power BI report-definition format.
